## 中文版（推荐）

Panda Dock 是一款完全本地运行的浏览器扩展：在任意网页上聚拢你日常重复的文本处理工作。

内置九个工具——JSON、JWT、URL、Base64、时间戳、Hash、二维码、Cookie 与网页存储；选中文字即可智能解析。全部在你的浏览器里完成：不联网、不上传、无遥测，唯一保存的是你自己的偏好设置。

免费、开源（MIT）。源码与问题反馈：https://github.com/forestRhapsody/panda-dock

隐私政策：https://forestRhapsody.github.io/panda-dock/zh-CN/privacy.html

## English

Panda Dock is a fully offline browser extension that gathers the text chores you keep repeating on any web page.

Nine tools in one panel — JSON, JWT, URL, Base64, Timestamp, Hash, QR Code, Cookies and Storage; select any text for Smart Parse. Everything runs in your browser: no network requests, no uploads, no telemetry. The only thing saved is your own preferences.

Free and open source (MIT). Source and issues: https://github.com/forestRhapsody/panda-dock

Privacy policy: https://forestRhapsody.github.io/panda-dock/en/privacy.html

## 填法要点

1. **不能只填一句**：商店 Description 有最小长度要求，且描述里看不清功能会直接影响搜索命中与转化；下限用「下限版」，推荐用「中文版/English」。
2. **开门见山**：先「是什么 + 不上传数据」，再展开功能；不要用「最强大 / 万能 / 第一」这类极限词，会被判夸大宣传。
3. **隐私句必须保留**（不联网、不上传、无遥测）：它同时是商店「数据用途」声明的语气佐证，需与隐私政策页措辞一致。
4. **不要逐条铺开九个工具的宣传小节**：主线收在「面向当前所见文本的解析与转换」，避免被判定为多功能集合而驳回单一用途。
5. **链接只留仓库与隐私政策**：描述里放站外下载或推广链接容易被拒。
6. **首屏约 200 字内**：商店默认折叠，前几句要能独立说清价值。
7. 功能措辞需与 `src/tools/registry.ts` 的 9 个工具 id 对应，不做名不副实的宣传。
