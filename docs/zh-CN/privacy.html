隐私政策

Panda Dock 是一个提供离线开发者工具的 Chrome 扩展。最后更新：2026-09-14。

1. 摘要

你输入、粘贴、划选或修改的内容，全部留在浏览器内部。扩展不发起任何网络请求，没有账号、没有服务端，也没有数据统计。我们看不到你的数据，也不出售、不共享。

2. 扩展会访问什么

只在你主动使用工具时访问，不在后台运行：

  • 页面存储 — 打开「网页存储」工具时，会读取当前页面的 Cookie 与 localStorage / sessionStorage，数据就地查看和修改，扩展不留副本。
  • 文本与文件 — 你粘贴或划选的文本、你选择打开的文件，均在浏览器本地解析。
  • 你的设置 — 存入 chrome.storage.sync；可选的悬浮球图片存入本机的 chrome.storage.local。
  • 会话输入 — 会话期间的工具输入存入 chrome.storage.session，浏览器关闭即清空。
  • 剪贴板 — 点击复制时写入；在工具中粘贴时读取。

以上所有内容随时可在设置页清除，卸载扩展也会一并删除。

3. 权限

权限 用途
storage 在本机保存设置、会话草稿和可选的悬浮球图片。
sidePanel 在 Chrome 侧边栏显示工具箱。
contextMenus 提供右键菜单快捷入口。
cookies 在「网页存储」工具中读写 Cookie。
http://*/*、https://*/* 向页面注入悬浮球；读取你划选的文本；打开「网页存储」工具时访问当前页面的存储。

没有申请其他权限。

4. Chrome 应用商店 Limited Use 声明

通过 Chrome API 获取的信息，仅用于实现扩展的单一用途：本地的开发者工具箱。不出售、不转移给第三方，不用于广告、用户画像或信用评估，也没有任何人会读取这些数据。
